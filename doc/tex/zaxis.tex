This section contains functions to define a vertical Z-axis.
A Z-axis object is necessary to define a variable.
The following different Z-axis types are available:

\vspace*{3mm}
\hspace*{8mm}\begin{minipage}{15cm}
\begin{deflist}{{\bf ZAXIS\_DEPTH\_BELOW\_LAND \ \ }}
\item[{\bf ZAXIS\_GENERIC           }]  Generic user defined level
\item[{\bf ZAXIS\_SURFACE           }]  Surface level
\item[{\bf ZAXIS\_HYBRID            }]  Hybrid level
\item[{\bf ZAXIS\_PRESSURE          }]  Isobaric pressure level in Pasal
\item[{\bf ZAXIS\_HEIGHT            }]  Height above ground in meters
\item[{\bf ZAXIS\_DEPTH\_BELOW\_SEA }]  Depth below sea level in meters
\item[{\bf ZAXIS\_DEPTH\_BELOW\_LAND}]  Depth below land surface in centimeters
\end{deflist}
\end{minipage}
