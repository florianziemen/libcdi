This section contains functions to define a horizontal Grid.
A Grid object is necessary to define a variable.
The following different Grid types are available:

\vspace*{3mm}
\hspace*{8mm}\begin{minipage}{15cm}
\begin{deflist}{{\bf GRID\_CURVILINEAR \ \ }}
\item[{\bf GRID\_GENERIC    }]  Generic user defined grid      
\item[{\bf GRID\_GAUSSIAN   }]  Gaussian latitude/longitude grid
\item[{\bf GRID\_LONLAT     }]  Equidistant longitude/latitude grid
\item[{\bf GRID\_SPECTRAL   }]  Spherical harmonic coefficients
\item[{\bf GRID\_GME        }]  Icosahedral-hexagonal GME grid    
\item[{\bf GRID\_CURVILINEAR}]  Curvilinear grid
\item[{\bf GRID\_CELL       }]  Unstructured grid cells
\end{deflist}
\end{minipage}
